# Rules — law and tax, dated (usually changes once a year)

Numbers that a script uses live in a `.json` beside the `.md` (the only copy); the `.md` explains them. Each rule has: the value, `effective from`, the GOV.UK (or legislation) source, `checked`, and `review by` (the next date it could change, normally 6 April or the Budget). When working on a period, use the row in force for that period, not the newest one.
